# CHAT specification fixtures

Batchalign retains these CHAT construct, error, and symbol documents as test
resources for parser-validation parity. The canonical parser, specification,
grammar, and generators live in the Chatter repository.

There is no local specification-generator crate or `just spec` workflow in
this repository. Files below this directory are historical fixture inputs;
Batchalign code must not depend on the removed generator implementation.
